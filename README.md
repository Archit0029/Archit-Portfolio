## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm
* Git
* Expo CLI

### Clone the repository

```bash
git clone https://github.com/Archit0029/Archit-Portfolio.git
cd Archit-Portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm start
```

### Run on Web

```bash
npm run web
```

Or:

```bash
npx expo start --web
```

## 📦 Production Build

Generate the production web version with:

```bash
npx expo export --platform web
```

The production files will be generated inside:

```text
dist/
```

## 🌐 Deployment

The portfolio is deployed using **Vercel**.

The deployment workflow is:

```text
Local Development
       ↓
Git
       ↓
GitHub
       ↓
Vercel
       ↓
Live Website
```

Every update pushed to the `main` branch can be automatically deployed through Vercel.
